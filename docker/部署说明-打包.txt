部署包说明（2026）
====================

目录（须平级、勿改名）
--------------------
  zuhaowaibao/     后端（含 sql/hxl_rent_full.sql 供 Docker 初始化）
  admin-ui/        管理后台前端
  ZhuHaoXiTong/    C 端 H5，脚本在 ZhuHaoXiTong/docker/

同事电脑要求
------------
  - Docker Desktop
  - 三文件夹与本文同级

一键全栈 Docker（推荐：已写死库连接与默认密码）
-----------------------------------------------
  cd ZhuHaoXiTong/docker
  docker compose -f docker-compose.all-in-one.yml up -d --build

  默认端口：API 3001，C 端 3002，后台 3003，MySQL 宿主机 3301，Redis 6379。
  MySQL root 默认密码：ZuhooDeploy123（与后端 application-fixed.yml 一致）。
  首次启动等待 1～2 分钟导入数据库。

  手机访问 C 端：http://同事电脑IP:3002 （勿用未配代理的 Vite 开发服。）

仅外链 MySQL/Redis（不设库容器）
--------------------------------
  cd ZhuHaoXiTong/docker
  复制 .env.example 为 .env，填 MYSQL_* / REDIS_* 后：
  docker compose -f docker-compose.yml --env-file .env up -d --build

重新打包（开发者本机）
----------------------
  powershell -ExecutionPolicy Bypass -File ZhuHaoXiTong\docker\_pack-deploy.ps1

说明：已排除 node_modules、.git；已包含预构建的 zuhaowaibao\target\*.jar 与两端 dist（若缺失请先在本机构建再执行打包脚本）。
Docker 仍可 up --build 重新构建镜像；本地也可用 jar + 静态目录自行部署。
